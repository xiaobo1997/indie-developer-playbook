# 12 - 推荐工具栈

## 选工具的原则

1. **先用免费的**：用出痛点再付费
2. **避免锁定**：开源优先
3. **少即是多**：能少用一个工具就少用一个
4. **可迁移**：数据格式开放

## 选工具的 5 个问题

1. **这能解决具体痛点吗？**
2. **有免费试用吗？**
3. **数据导出方便吗？**
4. **社区活跃吗？**
5. **未来 3 年还会存在吗？**

如果任何答案是"否"，谨慎选择。
