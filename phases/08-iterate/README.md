# 环节 08 · 数据迭代与变现（Iterate）

> **解决什么问题**：上线不是终点，是循环的开始：**数据 → 洞察 → 改版 → 数据**。这个环节也是收益的来源——大部分独立产品死于"不再迭代"，而不是"做错了"。

## 你要做什么

1. **定北极星指标（一次）**：选一个最能代表"用户得到价值"的数（工具类：周活跃；内容类：完读/完播；社区类：回访率）。别贪多，一个就够，其余是辅助指标。
2. **数据面板（半天搭好）**：
   - 小程序：官方后台「[We 分析/统计](https://mp.weixin.qq.com/)」免费覆盖打开数、留存、页面路径、流失点——**先用满官方的，别急着埋点**
   - Web 路线：[Umami](https://github.com/umami-software/umami)（轻量自托管）或 [Plausible](https://github.com/plausible/analytics)（隐私友好）
3. **反馈通道（持续运转）**：产品内「关于/反馈」入口 + 微信群 + 应用市场评论，每周清一次；每条反馈记三件事：谁（画像）、什么场景、要求解决什么——**用户说"要什么"是噪声，"卡在哪"是信号**。
4. **周复盘（每周固定 30 分钟，本环节的发动机）**：
   - 看数据：北极星动了吗？哪个页面流失最狠？
   - 看反馈：本周最痛的一件事是什么？
   - 定下版：只定 1-2 个改动（用 [workflow.md 的砍功能四问](../../docs/11-workflow/workflow.md)过滤）
   - 写进 [CHANGELOG](../../CHANGELOG.md)（模板见 [templates/changelog-template.md](../../templates/changelog-template.md)），重大方向变化写一条 [ADR](../../docs/decisions/)
5. **变现在验证之后再上（顺序不能反）**：先有留存，再谈付费。路径见下「变现路线图」。

## 变现路线图（小程序，按个人开发者现实程度排序）

| 路线 | 门槛 | 说明 |
|---|---|---|
| **流量主广告** | 个人主体可开；累计独立访客达标（UV≥1000，以后台为准） | 个人主体**唯一原生**变现；体验有损，适合工具类兜底 |
| **付费功能 → Web 端收单** | 需自建 Web + 支付通道 | 个人主体小程序不能开通微信支付；常见做法是小程序引流、Web 完成支付（iOS 虚拟支付另有限制） |
| **升级企业/个体户主体** | 营业执照 + 认证费（约 300 元/年，以官方为准） | 开通微信支付的正规路径；有稳定收入后再升级 |
| **实物/服务电商** | 相应类目 + 企业主体 | 类目资质要求高，不适合个人起步 |
| **带不走的收益**：咨询/定制/课程 | 无平台门槛 | 用产品当名片，卖你的时间与经验——独立开发者的隐藏现金流 |

> 规则以 [微信支付商户平台](https://pay.weixin.qq.com/) 与 [小程序运营规范](https://developers.weixin.qq.com/miniprogram/product/) 为准。

## 产出物

- 一句话北极星指标（写进项目 README）
- 周复盘记录（`reviews/2026-WXX.md`，一页一份）
- 持续更新的 CHANGELOG（用户可感知的版本记录）
- 变现通道（达成门槛后逐条点亮路线图）

## 完成标准（本环节是循环，标准是循环质量）

- [ ] 北极星指标选定且有看板能看到
- [ ] 反馈通道在产品内可触达，每周清理
- [ ] 连续 4 周有周复盘记录（这是本环节的最低门槛）
- [ ] 每个版本都有 CHANGELOG，重大转向有 ADR
- [ ] 变现路线明确：当前卡在哪条门槛、下一步点亮哪条

## 常见陷阱

- **看虚荣指标**：下载量/累计用户涨但周活跌——你在失去用户。"累计"是安慰剂，"每周"是体检表。
- **按声音大小排优先级**：最吵的用户 ≠ 最典型的用户。回到北极星：这个改动让"用户得到价值"更多吗？
- **大版本憋半年**：小步快跑，每周一个可见变化；用户流失经常发生在"这个产品好像没人管了"的观感上。
- **过早变现**：留存没起来就插广告/弹付费，杀鸡取卵。先证明"用户每周还回来"。
- **不复盘**：没有记录的迭代是随机漫步。周复盘 30 分钟是独立开发者投资回报率最高的半小时。

## 小程序主线注意点

- **官方统计先用满**：访问分析（来源/留存/路径）、性能监控、错误日志都在 MP 后台免费提供，个人项目 1000 用户内基本不需要第三方埋点。
- **订阅消息是留存抓手**：用户主动订阅后的关键事件提醒（如"今日单词已就绪"），合规且有效；滥用（打扰式推送）会被取关+投诉，以[官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/subscribe-message.html)为准。
- **流量主开通路径**：MP 后台「流量主」模块，达标后开通，广告位（banner/激励视频）按需选；激励视频体验最不伤产品，优先试。
- **支付相关的 iOS 限制**见 [phases/README.md](../README.md) 硬知识第 6 条；变现方案设计时先想清楚 iOS 用户的付费路径。
