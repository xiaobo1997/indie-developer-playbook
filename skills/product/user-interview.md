# Skill: 用户访谈

> 5 个用户、每次 30 分钟 = 完整用户研究

## 何时使用
- 想做新功能前
- 不确定需求时
- 验证产品方向

## 流程

### 1. 准备（30 分钟）
- [ ] 明确要解决的问题
- [ ] 写 5-10 个开放问题
- [ ] 招募 5 个目标用户
- [ ] 准备录音设备

### 2. 访谈（每次 30 分钟）

#### 开场（5 分钟）
```
"你好，感谢抽时间。这次访谈大约 30 分钟。
我想了解你在 [领域] 的工作经验。
所有内容保密，可以随时拒绝回答。"
```

#### 主要问题（20 分钟）
1. **背景**：你在做什么工作？多久了？
2. **现状**：现在怎么解决 [问题]？用了什么工具？
3. **痛点**：最大的挑战是什么？什么时候发生？
4. **理想**：理想情况下是什么样的？
5. **付费**：愿意付多少钱？
6. **现有方案**：用过哪些产品？哪里不满意？
7. **推荐**：朋友用你会推荐吗？

#### 收尾（5 分钟）
```
"还有什么我没问到但你想说的？
谢谢你！我会 [如何反馈]。
"
```

### 3. 记录（30 分钟）
- [ ] 整理录音（Otter.ai 自动转录）
- [ ] 提取关键洞察
- [ ] 写总结（不超过 1 页）

### 4. 决策（30 分钟）
- [ ] 从访谈提取需求
- [ ] 评估需求优先级
- [ ] 更新 PRD

## 问题模板

```markdown
## 用户访谈问题 - [主题]

### 暖场
1. 能介绍下你自己吗？
2. 你目前在 [领域] 工作多久了？

### 现状
3. 你现在怎么 [做这件事]？
4. 用什么工具？为什么？
5. 上周花了多少时间在这上面？

### 痛点
6. 这个过程中最头疼的是什么？
7. 什么时候会特别不爽？
8. 有没有"差点放弃"的时刻？

### 现有方案
9. 试过哪些产品？
10. 它们哪里让你不满意？

### 理想
11. 如果有魔法，你想要什么？
12. 多少钱愿意付费？
```
