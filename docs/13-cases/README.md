# 13 · 案例角色目录

> 案例不是鸡汤素材库，是**决策参照系**：读案例的产出必须是"我现在这个环节，抄哪一条、防哪一个"。禁止无目的刷案例——那是高级拖延。
> 三个深度复盘见 examples/；统计与失败模式见 [case-studies.md](case-studies.md)。

## 这个角色负责什么

| 负责 | 不负责 |
|---|---|
| 按当前环节匹配对应案例 | 替你做决策（案例是参照不是答案） |
| 从案例提炼"可抄的一条" | 复制产品本身（抄的是打法不是创意） |
| 维护失败模式清单的时效 | 预测哪个产品会成（没人能） |

**边界判定**：产出物是"对照结论 + 一条行动"；产出物是"又收藏了 10 个链接"就越界了。

## 独立跑完「案例学习」的流程

| 步 | 做什么 | 产出 | 耗时 |
|---|---|---|---|
| 1 | 说清当前卡在哪个环节（01-08 哪一步） | 一句话现状 | 5 分钟 |
| 2 | 只找该环节的案例段落读（对照表见下） | 对应案例 1-2 个 | 30 分钟 |
| 3 | 提炼一问一答：他能抄的一条是什么？我防的模式是哪个？ | 两条行动 | 15 分钟 |
| 4 | 把行动排进任务卡（进 phases 对应环节的 notes 或 tasks） | 一张任务卡 | 5 分钟 |

| 01 验证（不知道需求真假） | [nomadlist](../../examples/nomadlist/README.md)：先验证后开发（Sheet + 落地页投票） |
| 02 定义（范围收不住） | [shipfast](../../examples/shipfast/README.md)：一周上线的范围砍法 |

## 新手最容易踩的坑

| 坑 | 为什么会踩 | 怎么避 |
|---|---|---|
| 收藏当学习 | 刷案例很爽 | 每次只读一个，必须产出"一条行动" |
| 迷信个例 | 幸存者偏差 | 个例对照统计看（101 访谈表），个例找灵感、统计定纪律 |
| 抄产品不抄打法 | 看到成功想复刻 | 抄的是验证方式/分发渠道/节奏，不是产品创意 |
| 用别人的节奏骂自己 | "levelsio 一天上线我三个月没成" | 案例是参照系不是进度表 |
