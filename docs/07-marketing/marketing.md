# 07 - 营销

## 独立开发者的营销现实

### 营销 ≠ 销售
- **营销**：让对的人知道你的产品
- **销售**：让知道的人付钱
- 独立开发者要兼顾两者

### 营销的 80/20
- 80% 的效果来自 20% 的渠道
- 关键是找到**属于你产品**的那 20%

---

## 营销渠道

### Tier 1：高 ROI（独立开发者首选）

#### 1. Twitter/X
- **适合**：英文产品、SaaS、工具
- **怎么做**：
  - 每天发 1-3 条
  - 公开构建 (#buildinpublic)
  - 互动其他独立开发者
- **案例**：Marc Lou 90% 客户来自 Twitter
- **关键指标**：关注者增长、点击率

#### 2. 内容营销（博客 / YouTube）
- **适合**：长期 SEO、技术产品
- **怎么做**：
  - 写"how to build X"系列
  - 录屏开发过程
  - 教程型内容
- **案例**：Pieter Levels 直播编程
- **关键指标**：搜索流量

#### 3. Product Hunt
- **适合**：新发布的产品
- **怎么做**：
  - 准备"上线日"
  - 提前找支持者
  - 用 #1 product of the day 目标
- **关键指标**：当日排名

#### 4. Reddit
- **适合**：开发者工具、SaaS
- **怎么做**：
  - 在相关 subreddit 分享
  - 不要硬广，分享真实价值
- **关键指标**：upvote 数、流量

### Tier 2：可考虑

#### 5. 即刻 / V2EX（中文）
- **适合**：中文产品
- **怎么做**：发产品动态、参与话题

#### 6. 小红书 / 抖音
- **适合**：消费类产品
- **怎么做**：短视频教程

#### 7. Newsletter
- **适合**：长期用户关系
- **怎么做**：每周有价值内容

#### 8. SEO
- **适合**：有耐心的人
- **怎么做**：写搜索量大的关键词文章

### Tier 3：谨慎使用

#### 9. Google / Facebook 广告
- **优点**：可预期
- **缺点**：贵，独立开发者慎用
- **何时用**：已盈利、有 LTV 数据

#### 10. KOL / 网红
- **优点**：快速曝光
- **缺点**：难评估 ROI

## 公开构建（Build in Public）

### 为什么
1. **吸引早期用户**：他们想参与你的旅程
2. **建立信任**：透明 = 信任
3. **获得反馈**：实时改进
4. **个人品牌**：长期复利

### 怎么开始

#### 第 1 周
- 创建一个 Twitter 账号（专用）
- 写第一篇公开日记
- 介绍：你是谁、要做什么、为什么

#### 第 2-4 周
- 每天发 1-3 条
- 内容：进展、遇到的问题、学的知识
- 标签：#buildinpublic #indiehacker

#### 持续
- 真实进展（不要编）
- 错误和教训（更有共鸣）
- 数据和里程碑

### 内容模板

#### 进展帖
```
今天进展：
✅ 完成了 X
✅ 部署了 Y
⏳ 还在 Z 上挣扎

#buildinpublic
```

#### 经验帖
```
学到了：
原来 X 只需要 Y 行代码

代码示例：
[code snippet]

#javascript
```

#### 数据帖
```
本月数据：
- 用户：123 (+50%)
- MRR：$456 (+30%)
- 新功能：3 个

下一步：...
```

## 落地页（Landing Page）

### 必备元素
1. **Hero**：一句价值主张
2. **截图/视频**：产品演示
3. **Social proof**：用户数 / 评价
4. **功能介绍**：3-5 个核心功能
5. **价格**：透明定价
6. **CTA**：明显的行动按钮
7. **FAQ**：常见问题

### 工具
- **Framer** - 设计感强
- **Typedream** - 适合 SaaS
- **Carrd** - 单页便宜
- **Next.js + shadcn** - 完全自定义

### 转化率优化
- A/B 测试标题
- 测试 CTA 文案
- 测试价格展示
- 添加社会证明

## SEO（搜索引擎优化）

### 独立开发者 SEO 实战

#### 关键词研究
- **免费工具**：Google Keyword Planner、Ubersuggest
- **付费工具**：Ahrefs、SEMrush
- **技巧**：搜 "X alternative" 类关键词

#### 内容策略
- 写搜索量高的文章
- 解决用户具体问题
- 用工具型内容（如计算器、生成器）

#### 技术 SEO
- 页面加载速度 < 3s
- 移动端友好
- HTTPS
- 结构化数据
- Sitemap

## 增长黑客（Growth Hacking）

### AARRR 漏斗优化

#### Acquisition（获取）
- SEO
- 内容营销
- 社交媒体
- 付费广告

#### Activation（激活）
- 引导流程优化
- 首次体验价值
- 减少注册步骤

#### Retention（留存）
- 邮件提醒
- 推送通知
- 习惯养成
- 持续价值

#### Revenue（收入）
- 升级路径
- 升级提示
- 折扣策略
- 订阅模式

#### Referral（推荐）
- 推荐奖励
- 邀请好友得奖励
- 病毒式传播设计

### 病毒系数 K 公式
```
K = (邀请数 × 转化率)
如果 K > 1，自然增长
```

## 衡量

### 关键指标

#### 北极星指标（North Star）
- 能反映产品价值的单一指标
- 例：DAU、MRR、周活用户数

#### 营销指标
- CAC（用户获取成本）
- LTV（用户生命周期价值）
- LTV/CAC > 3 是健康

#### 转化率
- 访客 → 注册：2-5% 是平均
- 注册 → 付费：1-5% 是平均

### 工具
- **Google Analytics** / Plausible
- **Mixpanel** / PostHog
- **Stripe Dashboard** 看 MRR
