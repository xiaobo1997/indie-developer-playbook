# 环节 07 · 发布与增长（Launch）

> **解决什么问题**：酒香也怕巷子深。第一批 100 个用户不会自己来，也不会来自广告——来自你持续、真诚、在用户聚集地的**公开构建（Build in Public）**。营销对程序员最难，但它是每天 30 分钟的日常，不是天赋。

## 你要做什么

1. **发布前一周：备弹药**
   - 一段 30 秒的产品介绍（解决了谁的什么问题 + 一句价值主张）
   - 3-5 张使用截图/一段演示视频（真机录屏即可）
   - 一个反馈入口（微信群二维码 / 表单）
2. **发布日：一次「小而正式」的发布**
   - 渠道按优先级：**微信生态内**（朋友圈 + 相关微信群 + 即刻）→ 垂直社区（你的用户在哪发哪：学习类去豆瓣小组、效率类去少数派、程序员去 V2EX/掘金）→ 公开构建渠道（即刻/小红书/推特）
   - 帖子写法：「我做了一个 XX，因为我每次 YY 都很烦 → 它现在能 ZZ → 求反馈（附二维码）」。**讲故事 + 求反馈，不吹牛**。
3. **公开构建（持续，每天 15-30 分钟）**
   - 固定节奏：每 2-3 天一条进度（新功能/数据/踩坑），格式：`第 N 天 | 做了什么 | 学到什么`
   - 记住：**记录过程比宣传结果更容易获得共鸣**，早期没数据就晒过程
4. **免费流量 optimization（一次性 + 月度维护）**
   - 小程序名称、简介埋好用户会搜的关键词（微信搜一搜是小程序最大的免费流量来源）
   - 分享卡片（标题 + 图）认真设计——它决定了别人转发时的点击率
5. **冷启动目标定小**：第一批目标不是 1000 用户，是 **30 个愿意给你提意见的人**。建群、逐个聊、记录反馈进环节 08。

## 产出物

- 发布弹药包（介绍文案 + 截图/视频 + 反馈入口）
- 各渠道的发布记录（发了什么、在哪、反馈如何——后续复盘用）
- `content-log.md`：公开构建的流水账（这是你的营销资产，坚持一个季度就是复利）

## 完成标准

- [ ] 弹药包三件套就位
- [ ] 在 ≥3 个目标用户聚集的渠道发布过，并回复了每一条评论/私信
- [ ] 建立了反馈入口，第一批 ≥10 条真实反馈进来了
- [ ] 公开构建节奏坚持了 ≥2 周

## 常见陷阱

- **发一次就停**：90% 的流量来自第 2-10 次出现，不是第一次。定节奏（每周 ≥3 条）比爆款重要。
- **只在技术社区发**：程序员用户不付费、需求怪。去**目标用户**的社区（宝妈群、学生群、效率工具圈），哪怕你在那里没有粉丝。
- **把谦虚当卖点**：「只是个小工具，做得不好」——用户要的是确定性。大方说清楚它解决了什么。
- **买量/互粉/刷量**：虚假繁荣污染数据，让你环节 08 的决策全错。独立开发者的命根子是真实反馈。
- **没有反馈入口**：用户用完想说话却找不到地方，就永远流失了。入口要在产品内（关于页）和帖子末尾都有。

## 小程序主线注意点

- **微信搜一搜是主战场**：名称含核心关键词（如"XX 背单词"比"XX"好）、简介写清功能与人群、类目准确——这三件事决定搜索排名的底分（规则以[微信官方](https://developers.weixin.qq.com/miniprogram/product/)为准）。
- **分享是增长引擎**：小程序天然的「转发给朋友」，把分享卡片（5:4 图 + 标题）当成落地页来设计；分享出去的路径要直达内容页而不是首页。
- **诱导分享红线**：强制分享才能解锁、利益诱惑分享属违规，会被处罚（以官方规范为准）。增长动作都在合规线内做。
- **视频号/公众号联动**：有公众号可挂小程序入口；短视频演示（录屏 + 字幕）在视频号/小红书的转化远好于图文。
- **国内发布渠道参考**：即刻（产品人聚集）、小红书（消费/生活类）、少数派（效率工具）、豆瓣小组（兴趣类）、V2EX/掘金（开发者工具类）。
