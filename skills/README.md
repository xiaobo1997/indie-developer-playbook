# Skills - 可执行的 AI 工作流

> 每个 skill 是一个**指令集合**，可以让 AI 帮你完成具体工作。

## 什么是 Skill？

Skill = 提示词 + 工作流 + 检查清单

不是文档，而是**可执行的操作流程**。
