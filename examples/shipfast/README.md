# 案例：ShipFast

## 基本信息

- **产品**：https://shipfa.st
- **创始人**：Marc Lou (@marc_louvion)
- **类型**：Next.js SaaS 启动套件
- **价格**：$199（一次性）或 $99/年订阅

## 产品做什么

提供 Next.js SaaS 的完整 boilerplate：
- 鉴权（Clerk + NextAuth）
- 支付（Stripe + Lemon Squeezy）
- 数据库（Supabase + MongoDB）
- 邮件（Mailgun + Resend）
- 部署（Vercel）
- AI 集成
- 文档

## 为什么成功

### 1. 抓住需求
- 独立开发者都想要"快速启动"
- 自己写 boilerplate 太费时
- 一周能省一个月

### 2. 公开构建
- 每日公开收入
- 真实增长曲线
- 带来信任

### 3. 持续更新
- 紧跟技术趋势
- 加新功能
- 维护老用户

## 启示

1. **卖铲子比挖金子稳**
2. **公开数据建立信任**
3. **持续更新是关键**
4. **付费用户是终身价值**
