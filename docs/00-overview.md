# 00 - 独立开发者总览

## 什么是独立开发者？

**独立开发者 (Indie Hacker / Solo Founder)** = 一个人或 2-3 人小团队，做出完整产品并上线销售。

### 核心特征

- **一个人 = 一个团队**：自己做 PM、UI、前端、后端、运维、营销、客服
- **小而美**：追求利润率，不是用户数
- **产品驱动**：相信好的产品自己会说话
- **公开构建**：在社交媒体分享过程

### 与传统创业的区别

| 维度 | 传统创业 | 独立开发者 |
|---|---|---|
| 团队规模 | 5-100 人 | 1-3 人 |
| 启动资金 | 100 万+ | < 10 万 |
| 时间投入 | 全职 + 投资 | 兼职或全职 |
| 商业模式 | 融资驱动 | 现金流驱动 |
| 失败成本 | 投资人背锅 | 自己承担 |
| 退出策略 | 被收购/IPO | 长期运营 |

## 7 大角色

一个人要做 7 个角色：

### 1. PM 产品经理
**做什么**：找需求、定方向、写 PRD
**关键技能**：用户访谈、市场分析、MVP 设计
**工具**：Notion / 飞书 / Figma

### 2. UI/UX 设计师
**做什么**：设计界面、用户体验、品牌
**关键技能**：Figma、动效、设计系统
**工具**：Figma / 即时设计 / AI 工具

### 3. 前端开发
**做什么**：实现界面、交互、动效
**关键技能**：HTML/CSS/JS、React/Vue、小程序
**工具**：Cursor / VSCode / v0.dev

### 4. 后端开发
**做什么**：API、数据库、文件存储
**关键技能**：Node/Python/Go、SQL/NoSQL
**工具**：云开发 / Supabase / 自建

### 5. DevOps 运维
**做什么**：部署、监控、备份、安全
**关键技能**：Linux、Docker、CI/CD
**工具**：Vercel / Cloudflare / 阿里云

### 6. 市场营销
**做什么**：拉新、留存、品牌
**关键技能**：内容营销、SEO、社交媒体
**工具**：Twitter / 即刻 / Newsletter

### 7. 客服支持
**做什么**：回复用户、收集反馈
**关键技能**：沟通、同理心、文档
**工具**：邮件 / Discord / 微信群

## 收入模式

独立开发者常见收入模式：

### 订阅制 (SaaS)
- 月费/年费
- 例：Notion、Cursor
- 优点：可预测
- 缺点：需持续运营

### 一次买断
- 用户买永久 license
- 例：很多小工具
- 优点：简单
- 缺点：需持续获客

### 免费 + 内购 (Freemium)
- 基础功能免费，高级功能付费
- 例：飞书、印象笔记
- 优点：易传播
- 缺点：转化率低

### 广告
- 免费应用 + 广告
- 例：大部分免费 App
- 优点：用户量大即可
- 缺点：需要量大

### 增值服务
- 产品免费，专业服务收费
- 例：Vercel、Algolia
- 优点：高客单价
- 缺点：需要专业能力

### 混合模式
- 多种模式组合
- 例：免费 + 订阅 + 一次性

## 真实独立开发者案例

### Pieter Levels (🇳🇱)
- **作品**：Nomad List, Remote OK, Photo AI
- **方法**：单文件 PHP + jQuery + MySQL
- **特点**：30 天从 0 到 50 万 ARR
- **学习**：[makebook.io](https://makebook.io/)

### Marc Lou (🇫🇷)
- **作品**：ShipFast (启动套件)
- **方法**：开源 + 付费 license
- **特点**：每日公开收入
- **学习**：Twitter @marc_louvion

### Danny Postma (🇳🇱)
- **作品**：Headshot Pro
- **方法**：AI 产品 + SEO
- **特点**：从 0 到 100 万 ARR 用 6 个月

### Levels.io 经验总结
- 单仓库、单语言、单数据库
- 无构建工具，无 CI/CD
- 公开构建日记
- 不融资，不雇人

## 独立开发者的 5 个阶段

```
阶段 1: 学徒期 (0-3 个月)
  - 学习技能
  - 做小项目
  - 模仿成熟产品
  
阶段 2: 试水期 (3-12 个月)
  - 发布第一个产品
  - 获得第一个付费用户
  - 建立工作流
  
阶段 3: 起飞期 (1-2 年)
  - 月收入稳定 $1k-$10k
  - 多个产品组合
  - 形成自己的方法论
  
阶段 4: 自由期 (2-5 年)
  - 月收入 $10k-$100k
  - 远程工作 + 旅行
  - 开始影响他人
  
阶段 5: 平台期 (5 年+)
  - 月收入 $100k+
  - 被动收入 / 团队
  - 输出方法论 / 教学
```
