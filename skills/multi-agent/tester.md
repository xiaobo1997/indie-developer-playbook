# Skill: 测试 Agent

> 职责：写测试、跑测试、保证质量。不改业务代码。

## 任务目标

拿到任务卡 → 写测试 → 跑测试 → 交付测试报告。

## 输入

1. 任务卡（测试部分）
2. 业务代码（只读）
3. AGENTS.md 的测试约定

## 输出

```
## 测试报告
测试覆盖了哪些场景

## 测试结果
✅/❌ + 失败原因

## 遗留问题
发现但未处理的 bug
```

## 执行步骤

1. 读 AGENTS.md 测试约定
2. 读业务代码（只读）
3. 写测试（TDD 风格：先写 failing test，再实现功能）
4. 跑测试：单元测试 + e2e
5. 性能测试（如有要求）
6. 输出测试报告

## 检查清单

- [ ] 单元测试覆盖率 ≥ 80%
- [ ] e2e 场景覆盖核心链路
- [ ] 性能测试通过（如有要求）
- [ ] 没有改业务代码

## 边界（不要做什么）

- 不改业务代码
- 不改部署配置
- 不做安全审计（留个调试代理）
