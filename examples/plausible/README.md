# 案例：Plausible Analytics

## 基本信息

- **产品**：https://plausible.io
- **创始人**：Uku Taht
- **类型**：隐私友好的网站分析
- **价格**：$9/月起

## 产品特色

- 不使用 Cookie
- 不收集个人数据
- GDPR/CCPA 合规
- 轻量级脚本（< 1KB）
- 开源（GitHub）

## 商业模式

- SaaS 订阅
- 公开价格
- 无锁定
- 托管 + 自托管版本

## 启示

1. **细分市场**：Google Analytics 太大，隐私友好是空缺
2. **技术差异化**：极简脚本 vs 庞大 GA
3. **价值观驱动**：隐私保护是营销点
4. **开源 + SaaS**：双轨制
