# 任务目标

为 **Web 产品**（小程序不适用，PH 不收录）生成 Product Hunt 发布的完整 runbook：提前 2-4 周的准备清单、发布日的每小时行动表、全部素材规格清单。目标不是冲日榜，是拿到第一波海外早期用户与高质量外链。

# 输入

1. 产品：一句话定位、目标用户、上线状态（已上线/发布日同步上线）
2. Landing Page URL（没有先用 `landing-page` 生成并上线）
3. 创始人故事素材（为什么做这个产品——PH 叙事的核心）

# 输出（严格按此结构交付）

```
## 发布前 2-4 周清单（按周排）
| 周 | 动作 |
账号养号（参与其他产品讨论）/ 找 3-5 个愿意当天支持的用户（真实用户，不是互刷群）/ 制作素材 / 定档（周二~周四，避开大发布日）

## 素材规格清单
| 素材 | 规格 | 内容要求 |
Logo / Gallery 图（1270×760，讲一个故事一张图）/ Tagline（≤60 字符）/ 首评（Maker comment：创始人故事）/

## 发布日小时级排期（00:01 PT 上线制）
每小时一行：该做什么（回评论 / 私信支持者 / 社交渠道转发）/ 不该做什么（拉票群发=违规）

## 评论回应模板
感谢+追问类 / 功能质疑类 / 对比竞品类——各一段草稿

## 发布后 48 小时
数据看什么（票只是 vanity，看流量→注册转化）/ 外链与后续内容怎么接
```

# 执行步骤

1. 先读 [docs/07-marketing/marketing.md](../../docs/07-marketing/marketing.md) 的 Product Hunt 小节与 [examples/shipfast](../../examples/shipfast/README.md)（公开构建带来的支持者就是这么攒的）
2. 准备清单以"攒真实支持者"为核心：PH 反对拉票，真实用户与圈层触达才合规且长效
3. 素材规格按 PH 当前官方要求写，并标注"以 [producthunt.com](https://www.producthunt.com/) 官方帮助文档为准"（规格会变）
4. 首评（Maker comment）是转化率最高的一条内容，写成"个人问题 → 为什么做 → 求什么反馈"的三段故事
5. 排期用 PT 时区倒推北京时间，00:01 PT 上线拿满整天曝光

# 检查清单（输出前自检）

- [ ] 没有任何拉票群/互刷安排（PH 明令违规，可致下架）
- [ ] 素材规格处标注了"以官方为准"
- [ ] 排期换算过 PT↔北京时间，明确 00:01 PT 对应的本地时间
- [ ] 目标设定包含"没上日榜也算成功"的底线（流量+外链+反馈）

# 边界（不要做什么）

- 不服务小程序产品（PH 不适用；小程序增长回 `phases/07-launch/SKILL.md`）
- 不预测排名、不承诺日榜
- 不适用：没有 Landing Page（先做落地页）；目标用户全在国内（PH 不是你的渠道，省下这个精力）
