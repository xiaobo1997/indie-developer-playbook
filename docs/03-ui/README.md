# 03 · UI 角色目录

> 这是 **UI/UX 角色** 的自包含目录，可以单独拷走使用——文末「带走清单」列出了需要一并复制的文件。
> 对应环节：[环节 03 UI/UX 设计](../../phases/03-design/README.md)；角色分工约定见 [ADR-0005](../decisions/0005-roles-as-independent-skill-trees.md)。

## 如果你主要写后端（转全栈做 UI）

做 UI 时最大的坑**不是画得不好看，是根本不知道该画什么**。这不是审美问题，是流程问题。

正确的顺序是：先想清楚功能 → 认出页面骨架 → 再去抄同类项目。**跳过前两步直接开画，就是在凭空想象**——这正是本目录存在的意义：给你一条不依赖天赋的流程，和一批能直接打开的参考。

后端背景在这里其实是优势：你天然会把界面理解成「数据的展示 + 状态的切换」，而 UI 设计的绝大部分工作恰恰就是这两件事。

## 这个角色负责什么

| 负责 | 不负责 |
|---|---|
| 页面清单、信息架构、交互流程 | 品牌视觉、插画、动效细节 |
| 选组件库、定 design tokens | 写实现代码（那是前端角色） |
| 定义空 / 加载 / 错误三种状态 | 技术选型、接口设计 |

**职责边界的判定**：如果一件事最终产出的是「布局与状态定义」，归 UI；产出的是「能跑的代码」，归前端。

## 独立跑完环节 03 的流程

| 步 | 做什么 | 产出 | 耗时 |
|---|---|---|---|
| 1 | 核心功能守门：一句话定义只能有一个动词；三个问题砍功能 | 一句话产品定义 | 30 分钟 |
| 2 | 写页面清单：每页只回答「用户进来干什么」 | `pages.md` | 1 小时 |
| 3 | 认出自己需要哪几种页面骨架（6 种，见下） | 骨架清单 | 15 分钟 |
| 4 | 去参考项目里找同类的那一屏，只看那一屏 | 截图 / 结构笔记 | 1 小时 |
| 5 | 用线框工具按手机比例画出来，切三态检查 | 可预览线框 | 30 分钟 |
| 6 | 选组件库，只做三个决定（主色 / 圆角 / 字阶） | `design-tokens.md` | 半天 |

**步 1、2 不能跳。** 没做就去看参考，你会抄回一堆用不上的页面。

**代码写完之后还有一步闭环**：把真实产品截图回给 AI 评审，让它报问题再改。浏览器渲染、真机字号、数据撑开后的布局，只有跑起来才看得到——AI 生成的是方案，真实产品才是答案。完整流程与 prompt 见 [ai-as-designer.md](ai-as-designer.md)。

## 真实参考（不用凭空想象）

### 页面骨架：独立应用的界面就这 6 种

| # | 骨架 | 长什么样 | 新手最容易做错 |
|---|---|---|---|
| 1 | Dashboard | 顶部 2-4 个 KPI 卡 → 下方图表 / 列表 | 卡片太多，一屏超 4 个数字就没焦点 |
| 2 | 列表 + 详情 | 搜索 + 筛选 → 条目 → 点进详情 | 只做「有数据」的样子，忘空态 / 加载 |
| 3 | 表单 | 分组标题 → 单列输入 → 底部固定按钮 | 字段堆一屏，应拆成 2-3 步 |
| 4 | 设置 | 分组导航 → 每行一个设置项 | 当功能页做，塞一堆操作按钮 |
| 5 | 落地页 | 价值主张 → 截图 → 3 特性 → 定价 → CTA | 讲功能不讲结果 |
| 6 | 空态 | 图标 + 一句话 + 一个按钮 | 留白，或只写「暂无数据」——这是新用户第一屏 |

### 怎么最快看到界面

1. 仓库 README 首屏截图（30 秒判断风格对不对）
2. 官方在线 demo（README 里有地址；打不开就回仓库看截图）
3. `git clone` + Quick Start 本地跑一遍（最慢但最真实，值得为你最想抄的那一个项目做一次）

## 新手最容易踩的坑

| 坑 | 为什么会踩 | 怎么避 |
|---|---|---|
| 在 Figma 里精修一周 | 以为设计稿就是产出 | 对单人项目是负资产——写代码时反正要重排。草图 → 直接在真组件上迭代 |
| 混用多个组件库 | 想取各家之长 | 两套设计语言打架，比丑更致命。一个项目一个库 |
| 发明新交互 | 想做出差异化 | 下拉刷新、返回手势这些已被教育过的模式照做；「创新交互」留给产品成功之后 |
| 只画「有数据」的样子 | 脑子里默认有数据 | 三态（空 / 载 / 错）是硬要求，上线后白屏就是漏了这个 |
| 靠颜色救结构 | 觉得加点颜色就好了 | 灰度化测试：转黑白后层级还清楚才算对；分不清就该改结构 |
