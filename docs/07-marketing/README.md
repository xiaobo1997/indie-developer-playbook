# 07 · 营销角色目录

> 营销角色管"让对的人知道你"。程序员最容易跳过它，但它是每天 30 分钟的日常，不是天赋。原则：**公开构建、真实反馈、永不买量刷量**。
> 对应环节：[环节 07 发布与增长](../../phases/07-launch/README.md)。

## 这个角色负责什么

| 负责 | 不负责 |
|---|---|
| 发布弹药包、渠道选择、内容节奏 | 改产品功能（把反馈交给 PM 角色） |
| 落地页文案、公开构建流水账 | 承诺增长数字（没人能承诺） |
| 小程序 ASO（名称/简介/分享卡片） | 买量、刷量、诱导分享（红线） |

**边界判定**：产出物是"内容与渠道动作"；产出物是"产品改动"就越界了——那要把反馈整理后交给 PM。

## 独立跑完「营销工作」的流程

| 步 | 做什么 | 产出 | 耗时 |
|---|---|---|---|
| 1 | 备弹药：30 秒介绍 + 截图/录屏 + 反馈入口 | 弹药包三件套 | 半天 |
| 2 | 选 2-5 个"目标用户密度最高"的渠道 | 渠道清单（附为什么是它） | 1 小时 |
| 3 | 发布周执行：单渠道执行卡逐张打勾 | 发布记录 | 发布日 2 小时 |
| 4 | 转常态：周更内容系统 + 每周 15-30 分钟公开构建 | `content-log.md` | 每周 2-3 小时 |
| 5 | 小程序免费流量：名称/简介埋词 + 分享卡片打磨 | ASO 检查记录 | 一次性 + 月度维护 |

**渠道速查**：中文产品主战场 = 微信搜一搜（免费流量第一）+ 即刻 + 少数派/小红书；海外 = X #buildinpublic + Product Hunt。分级详表见 [marketing.md](marketing.md)。

## 收什么 → 交什么

| 上游交给我 | 我交给下游 |
|---|---|
| PM 角色：一句话定位 + 目标用户画像 | → PM 角色：用户反馈汇总表（进环节 08 复盘） |
| DevOps 角色：稳定的线上地址 | → 客服角色：新用户与其问题 |
| UI 角色：可用的截图/演示素材 | → 财务角色：渠道带来的付费线索 |

## 新手最容易踩的坑

| 坑 | 为什么会踩 | 怎么避 |
|---|---|---|
| 发一次就停 | 没人回应就羞于再发 | 90% 流量来自第 2-10 次出现；定节奏不定爆款 |
| 在技术社区发消费产品 | 程序员只熟技术社区 | 按"目标用户密度"选渠道，哪怕你在那儿零粉丝 |
| 买量刷量 | 数据好看缓解焦虑 | 假数据污染环节 08 全部决策；101 访谈反模式 F |
| 诱导分享 | 增长焦虑 | 微信红线，处罚以官方规范为准 |
| 没有反馈入口 | 觉得产品会自己说话 | 产品内"关于"页 + 每条帖子末尾都放 |
