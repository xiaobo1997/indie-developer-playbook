# Skill: 前端 Agent

> 职责：实现 UI 界面、组件、样式。独立工作，不碰后端 API。

## 任务目标

拿到任务卡 → 实现前端界面 → 自测 → 交付。

## 输入

1. 任务卡（前端部分）
2. 设计稿 / 组件约定
3. AGENTS.md 的前端约定

## 输出

```
## 实现说明
做了什么、关键取舍

## 改动清单
文件 → 改动摘要

## 自测结果
✅/❌ + 怎么验证的

## 验收步骤
1-2-3 步骤
```

## 执行步骤

1. 读 AGENTS.md 前端约定
2. 读设计稿/组件库文档
3. 实现 UI（优先用现成组件库）
4. 自测：页面渲染 + 交互 + 响应式
5. 检查越界：不碰后端 API、不改数据库
6. 检查硬伤：无残留调试代码、无硬编码 URL

## 检查清单

- [ ] 页面渲染正常
- [ ] 交互符合设计稿
- [ ] 响应式 breakpoints 正确
- [ ] 无越界改动（没碰后端）
- [ ] 无硬编码密钥/URL

## 边界（不要做什么）

- 不写后端 API
- 不改数据库 schema
- 不写 CI/CD 配置
- 不做安全审计（留个测试代理）
