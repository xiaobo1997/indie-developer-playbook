# 09 - 财务与收款

## 独立开发者的财务管理

### 为什么要重视
- 现金流决定生死
- 税务合规避免罚款
- 数据驱动定价

---

## 定价策略

### 4 种基础模式

#### 1. 免费 / Freemium
- 基础功能免费，高级付费
- 例：飞书、Notion
- 优点：易传播
- 缺点：转化率低（1-5%）

#### 2. 订阅制 (SaaS)
- 月费 / 年费
- 例：Cursor、Linear
- 优点：可预测
- 缺点：需持续运营

#### 3. 一次买断
- 永久 license
- 例：Sketch、Bear
- 优点：简单
- 缺点：需持续获客

#### 4. 用量计费 (Usage-based)
- 按 API 调用等
- 例：AWS、Algolia
- 优点：公平
- 缺点：用户难以预测成本

## 定价心理学

### 数字选择
- **$9 / $19 / $49** 比 $10 / $20 / $50 更划算的感觉
- **$99** 比 $100 更易接受

### 价格锚定
```
套餐 1:  $9/月  - 个人
套餐 2:  $29/月 - 团队 ⭐ 推荐
套餐 3:  $99/月 - 企业
```
- 大部分人选中间
- "$29" 显得划算

### 年付折扣
- 月付 → 年付：给 16-20% 折扣
- 用户省 2 个月
- 你获得现金流

### 免费试用
- 14 天 vs 30 天：越长转化越好，但流失也快
- 不需要信用卡：降低门槛
- 需要信用卡：质量更高

## 收款平台

### 全球收款

#### Stripe
- **价格**：2.9% + 30¢ / 交易
- **优点**：API 最强、文档最好
- **缺点**：国内不方便
- **适合**：海外用户

#### Paddle
- **价格**：5% + $0.50 / 交易
- **优点**：帮你处理税务（Merchant of Record）
- **适合**：海外销售 + 自动税务

#### Lemon Squeezy
- **价格**：5% + $0.50 / 交易
- **优点**：与 Paddle 类似，更简单
- **适合**：独立开发者

#### Gumroad
- **价格**：10%（贵）
- **优点**：超简单
- **缺点**：抽成高
- **适合**：单次销售

### 国内收款

#### 微信支付
- 费率：0.6-1%
- 需要：营业执照
- 通过：微信支付商户平台

#### 支付宝
- 费率：0.55-1.2%
- 个人可开通（部分受限）

#### 银联
- 费率：0.3-0.78%
- 大额首选

## 税务合规

### 海外销售

#### 美国销售税 (Sales Tax)
- **阈值**：跨州销售超过一定金额要收
- Stripe Tax 自动处理

#### 欧盟 VAT
- **阈值**：超过 €10,000 要注册
- 需要 VAT 号
- 推荐：**Paddle / Lemon Squeezy** 自动处理

#### 中国大陆
- 个人月收入 < 10万：免增值税
- 全部要交个人所得税
- 推荐：**办个体工商户**（核定征收，综合税率 1-3%）

### 关键原则
- **不要逃税**：被发现代价巨大
- **用正规平台**：Stripe/Paddle/Lemon Squeezy 帮你处理海外
- **国内办个体户**：比想象的简单

## 收入管理

### MRR / ARR 追踪

#### MRR (Monthly Recurring Revenue)
```
新增 MRR + 扩展 MRR - 流失 MRR = 净 MRR
```

#### ARR
```
MRR × 12 = ARR
```

### 关键指标

#### 流失率 (Churn)
```
月流失率 = 本月流失用户 / 上月活跃用户
```

#### LTV (Lifetime Value)
```
LTV = ARPU / 月流失率
```

#### LTV/CAC
```
健康：> 3
```

#### 回本周期 (Payback Period)
```
CAC / 月毛利 = 回本月数
```

## 法务基础

### 必备文档

#### 服务条款 (Terms of Service)
- 模板：Termly.io、TermsFeed
- 必须包含：免责声明、责任限制

#### 隐私政策 (Privacy Policy)
- 必备
- 工具：**Termly.io**、**iubenda**
- 要符合 GDPR / CCPA

#### Cookie 政策
- 欧洲必备

#### 退款政策
- 明确、可执行

### 知识产权

#### 商标
- 美国：USPTO 注册
- 中国：国家知识产权局
- 欧洲：EUIPO
- 成本：$250-350/类

#### 版权
- 自动获得，无需注册

## 现金流管理

### 独立开发者的财务缓冲

#### 建议储备
- **6 个月生活费**：心理安全
- **3-6 个月运营成本**：避免资金压力

### 常见陷阱
- 高 CAC（获客成本）
- 低 LTV（用户价值）
- 现金流为负
- 税务罚款

### 13 周现金预测

「现金流断裂与濒临破产」在 101 场创始人访谈中被提及 **13 次**，是全部失败模式中第二高频的一个，也是唯一一个**会直接终止项目**的（其余大多还能靠转向挽救）。它的根因几乎无一例外：没验证 → 没 PMF → 没收入——所以这其实是一个产品问题伪装成的财务问题。

对策是做 13 周（一个季度）滚动预测，而不是等到账上没钱才看：

| 周 | 预计收入 | 预计支出 | 期末余额 |
|---|---|---|---|
| W1 | | | |
| W2-W12 | | | |
| W13 | | | |

每周花 10 分钟更新一次。它的价值不在于预测准，而在于**把决策窗口从「没钱那天」提前了 13 周**：任一周期末余额跌破安全线时，你有时间选择涨价、砍成本，还是回去补验证。
